# regex-cron-toolbox

> Regex ve cron ifadelerini açıklayan geliştirici araç kutusu

Bu depo aktif geliştirme altındadır. Amaç; Linux, Windows ve Termux üzerinde kolay kurulabilen, açık kaynak ve topluluk katkısına uygun bir başlangıç sunmaktır.

## Durum

**Başlangıç sürümü / scaffold.** Özellikler aşamalı olarak eklenecektir.

## Kurulum

### Linux

```bash
git clone https://github.com/cyberorji/regex-cron-toolbox.git
cd regex-cron-toolbox
```

### Windows (PowerShell)

```powershell
git clone https://github.com/cyberorji/regex-cron-toolbox.git
Set-Location regex-cron-toolbox
```

### Termux

```bash
pkg update
pkg install git
git clone https://github.com/cyberorji/regex-cron-toolbox.git
cd regex-cron-toolbox
```
